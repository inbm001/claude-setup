2026-10-24: 웹 todo → 이 세션 실시간 지시를 "관리 사이트로는 어렵다, 수 분~30분" 이라고 답했는데, 다른 세션이 맥에서 서버에 연결을 열어 두고 기다리는 백그라운드 작업(watch)을 걸어, 새 댓글이 오면 작업이 끝나 세션이 즉시 깨어나는 방식으로 0.1초 만에 해냈다. 백그라운드 작업이 끝나면 세션이 깨어난다는 것은 이미 쓰고 있던 기능이었다. 사용자는 이 차이를 찜찜해 했다.

**Why:** "서버가 맥을 부를 수 없다 → 주기적으로 가져와야 한다 → 예약 작업" 으로 바로 좁혀서, 맥이 먼저 연결을 열고 기다리는 길을 따져 보지 않았다.

**How to apply:** 안 된다 · 어렵다 · 느리다고 답하기 전에 이 환경의 수단을 먼저 늘어놓는다 — 백그라운드 작업 끝남 알림, Monitor, 세션 간 메시지, 아티팩트 지켜보기, 예약 작업. 시험하지 않은 결론은 "확인 안 함" 으로 말한다. [[remote-wake-task]] [[issues-table]]
